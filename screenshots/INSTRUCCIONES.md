# Instrucciones para capturas de pantalla

Ejecuta ambas apps y toma las siguientes capturas. Guárdalas en esta carpeta con los nombres indicados.

## PWA (`pwa-mediclinic`)

1. **pwa-login.png** — Pantalla de login
2. **pwa-pacientes.png** — Dashboard con al menos 2 pacientes registrados
3. **pwa-busqueda.png** — Búsqueda activa filtrando resultados

## Ionic (`ionic-mediclinic`)

1. **ionic-login.png** — Pantalla de login
2. **ionic-visitas.png** — Tab Visitas con la lista del día
3. **ionic-detalle.png** — Detalle de una visita (botón cambiar estado visible)
4. **ionic-perfil.png** — Tab Perfil con datos del médico
